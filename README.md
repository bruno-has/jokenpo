# 🪨 Jokenpô

Um jogo simples de Jokenpô implementado em um site, onde você joga contra a máquina. Escolha uma opção, veja a escolha do computador e acompanhe o placar.

## 📌Como funciona
1. Clique em **Pedra** ou **Papel** ou **Tesoura**.
2. A máquina faz sua escolha automaticamente.
3. O resultado é exibido (se você ganhou, perdeu ou empatou) e o placar é atualizado.
4. Clique em **"Zerar placar"** para reiniciar as vitórias, empates e derrotas.

## 🛠️Tecnologias utilizadas
- **HTML5** – Estrutura da página  
- **CSS3** – Estilos visuais  
- **JavaScript (Vanilla)** – Lógica do jogo e manipulação DOM
